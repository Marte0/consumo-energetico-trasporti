# Consumo dei trasporti secondo il vettore energetico nel tempo

Infografica interattiva che mostra l'evoluzione del consumo energetico dei trasporti, suddiviso per vettore energetico, dal 2000 al 2025.

**[Apri la visualizzazione interattiva](https://energy-atlas-switzerland.themarta2001.chatgpt.site/)**

## Funzionalità

- selezione dell'anno tramite slider;
- grafico ad anello animato con valori assoluti e percentuali;
- evidenziazione coordinata tra gli spicchi e le categorie;
- impaginazione responsive per desktop e dispositivi mobili.

## Tecnologie

HTML, CSS, JavaScript, D3.js e Vite.

## Avvio locale

```bash
npm install
npm run dev
```

## Fonte dei dati

[Ufficio federale di statistica](https://www.bfs.admin.ch/bfs/it/home/statistiche/cataloghi-banche-dati.assetdetail.36777266.html)
